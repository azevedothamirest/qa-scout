# Ideias, bugs e feedback

Obrigada pelo interesse no QA Scout! O código é aberto, mas o desenvolvimento é feito só por mim. A melhor forma de ajudar é contar o que você viu e o que gostaria de ver.

## Como me mandar

Use os modelos de issue do repositório:

- **Bug**: de QA para QA, capriche nos passos para reproduzir, no resultado esperado e no obtido.
- **Ideia**: funcionalidade, heurística nova para o baralho, integração.
- **Feedback**: como foi usar, o que ajudou e o que atrapalhou.

[Abrir uma issue](https://github.com/azevedothamirest/qa-scout/issues/new/choose) · ou escreva para **contato.qascout@gmail.com**.

Não estou aceitando pull requests de código por enquanto: mande a ideia, que eu cuido da implementação.
